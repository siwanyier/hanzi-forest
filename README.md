# 汉字森林 · Hanzi Forest

一个适合亲子陪伴的汉字学习静态网站，包含 464 个汉字、字词句学习、原创故事、普通话音频和间隔复习。

## 本地运行

无需安装依赖，使用 Python 3 启动：

```bash
python3 -m http.server 8080 --directory dist
```

然后打开 http://localhost:8080 。也可以将 `dist/` 目录部署到任意静态网站服务器。

## 功能

- 464 个汉字与对应词语、例句；每轮默认 24 道认字题。
- 基础和进阶模式，听词选字、形近字辨析、组词及阅读理解。
- 答错后间隔重练，并在下一轮优先复习。
- 预置普通话词语、例句和故事音频，设备语音作为备用。
- 家长自定义字表、学习节奏和进度导入导出。

## 数据与隐私

学习记录保存在当前浏览器的 localStorage 中，不会自动同步到服务器。仓库不包含个人学习记录、姓名、账号凭据或原站点配置。导入的备份和家长自填内容只在本机处理；自定义内容的备用朗读优先选择设备本地普通话声音。页面使用 Google Fonts，字体加载时会向其服务发起网络请求。

## 验证

需要 Node.js：

```bash
npm test
```

## 目录与音频

- `dist/`：可直接部署的页面、脚本和音频。
- `scripts/`：固定教学语料与音频生成脚本；日常使用无需运行。
- `tests/`：学习逻辑与音频资源检查。

预置词语音频来源于有道及 Google 普通话服务，原创例句和故事音频来源于 Google 普通话服务。音频来源信息不代表第三方授予了额外的再分发许可。
